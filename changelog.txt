Version: 0.1.8
Date: ???
  Features:
    - Pyroclast Factory: new 7x7 general-purpose manufacturing building for producing enhanced equipment. Uses ammo-facility sprites with blue tint as placeholder graphics.
    - New crafting category: pyroclast-manufacturing. Used by Pyroclast Factory, Ammo Facility, and MPF.
    - Small Arms category: Pyroclast Firearm Magazine (+50% dmg), Piercing Rounds (+40%), Uranium Rounds (+30%), Shotgun Shell (+50%).
    - Medical category: Pyroclast Repair Pack (2x durability, 1.5x speed), Pyroclast Defender Capsule (+50% dmg, 2x HP combat robot).
    - Uniforms category: Pyroclast Modular Armor (7x7 grid), Power Armor (9x9 grid), Power Armor MK2 (12x12 grid), Mech Armor (12x12 grid). All with improved resistances.
    - Utility category: Pyroclast Grenade (+50% dmg, +25% radius), Pyroclast Cluster Grenade (+40% dmg, +25% radius).
    - Pyroclast Defender: enhanced combat robot entity spawned by Pyroclast Defender Capsule.
    - Scrap Recycling: probabilistic recipe to recover iron plate, steel plate, copper plate and calcite from pyroclast-scrap using sulfuric acid. Unlocked by Pyroclast Materials tech.
    - Five new technologies: Pyroclast Factory, Small Arms, Medical Supplies, Uniforms I & II, Utility Equipment. All require 10 science packs including electromagnetic and pyroclast.
  Changes:
    - Ammo Facility now uses pyroclast-manufacturing category instead of vanilla crafting categories. No longer able to craft arbitrary vanilla recipes.
    - Artillery Shell and Atomic Bomb recipes moved to pyroclast-manufacturing category.
    - Recipe categories moved from inline data.lua declaration to prototypes/recipe-categories.lua for cleaner file structure.
    - Fixed locale for upgrade technologies (pyroclast-assembly) to use base name format compatible with upgrade = true.

Version: 0.1.6
Date: 2026-03-01
  Features:
    - Cargo drop restrictions via PlanetsLib: most cargo drops to Pyroclast are blocked until the new "Pyroclast Cargo Drops" technology is researched. Basic logistics (belts, inserters, pipes, power poles, drills, assemblers) can still be dropped for initial base setup.
    - Recycler permanently blocked on Pyroclast. The extreme pressure (6000) is incompatible with the recycler's operation, preventing players from recycling Pyroclast items back into base game materials.
    - Pyroclast-exclusive items: instead of touching base game recipes, we now have dedicated enhanced items that give players a real reason to set up shop on Pyroclast.
    - Pyroclast Artillery Shell: base artillery shell infused with emat and bmat, +25% range. Requires artillery research.
    - Pyroclast Rocket: enhanced explosive rocket using emat and assmat1.
    - Pyroclast Atomic Bomb: supercharged nuke with hemat and assmat3. Requires atomic-bomb research.
    - Pyroclast Construction Robot: +50% speed, double HP. Built from a base construction robot + assmat2 and rmat.
    - Pyroclast Logistic Robot: same buffs as construction variant, logistic version.
    - Pyroclast Radar: doubled scan range, built with rmat and assmat1.
    - Crate system for all Pyroclast materials (bmat, cmat, emat, rmat, hemat, assmat1-4). Pack on Pyroclast, unpack anywhere. 5x transport density for inter-planetary logistics.
    - Four new technologies: Pyroclast Munitions, Pyroclast Nuclear Ordnance, Pyroclast Robotics, Pyroclast Radar.
    - Pyroclast Logistics technology unlocks all crate pack/unpack recipes.
    - Added Coal Power Plant and Ammo Facility buildings (from previous dev builds).
  Changes:
    - Removed all base game recipe modifications. Artillery shells, vehicles, robots etc. keep their vanilla recipes. The old approach caused mod compatibility headaches and forced players into Pyroclast progression whether they wanted it or not.
    - Assmat materials now have a clear purpose: assmat1 goes into rockets and radar, assmat2 into robots, assmat3 into the atomic bomb. assmat4 is still reserved for the rocket silo.
    - Technologies now properly require base game prerequisites (e.g. pyroclast-munitions needs artillery + rocketry, pyroclast-nuclear needs atomic-bomb research).
    - Refactored all prototype files to use data:extend() internally instead of returning tables. Aggregator files are now just simple require() lists. Much cleaner to maintain.
    - All new items use layered icons (base game icon + small Pyroclast material overlay) instead of separate generated icons.
    - Added PlanetsLib as a dependency for cargo drop management.

Version: 0.1.5
Date: 2026-02-24
  Features:
    - Added Pyroclast Refinery (7x7, foundry-based). Has +150% built-in productivity, no productivity modules allowed. Speed/quality/efficiency OK. 4 module slots, 3500kW.
    - Added Mass Production Factory (11x11). Same recipes as the Refinery with +50% built-in productivity for bulk runs. 5 module slots, 1200kW.
    - Added two new minable resources on Pyroclast: Scrap (common, ash biomes) and Components (rare, ash biomes). Both have map gen sliders.
    - Added Pyroclast Refinery and MPF technologies.
    - New custom icons for all materials and buildings.
  Changes:
    - Reworked the entire material production chain. All recipes moved from chemical plants to the new Pyroclast Refinery/MPF (pyroclast-refining category).
    - Base materials (bmat, emat, hemat) now require Scrap + lava instead of vanilla items.
    - Advanced materials (cmat, rmat) now require Components + lava instead of vanilla items.
    - Hemat uses sulfuric acid (pumped from planet surface) as a unique ingredient.
    - Pyroclast Scrap is its own resource, not Fulgora's scrap. This prevents players from hand-crafting the scrap-recycling recipe to get free vanilla items.
    - pyroclast-materials tech now requires pyroclast-refinery tech.

Version: 0.1.0
Date: 2026-02-23
  Features:
    - Initial standalone release, extracted from LavaBlock mod
    - Pyroclast planet: hyper-volcanic world with extreme pressure (6000) and gravity (60), reachable from Vulcanus
    - Sulfuric acid lakes: pumpable natural acid pools on the planet surface
    - Molten Iron and Molten Copper Geysers with configurable map generation sliders
    - Minable volcanic rocks (huge and big) yielding stone and ores
    - Obsidian: volcanic glass mineral extracted from lava under Pyroclast surface conditions
    - Pyroclast Science Pack: late-game research pack crafted from obsidian, metallurgic science packs, processing units, and lava
    - Foxhole-style material system:
      - Bmat (Basic Material): simple structural material from stone and iron
      - Cmat (Construction Material): reinforced building material
      - Emat (Explosive Material): volatile compound for military applications
      - Rmat (Refined Material): high-grade alloy for advanced equipment
      - Hemat (Heavy Explosive Material): powerful military-grade explosive
      - Assembly Materials I-IV: tiered vehicle and robotics components
    - Full technology tree: planet discovery, science pack, materials, explosives, refined materials, heavy explosives, assembly tiers 1-4
    - Base game recipe modifications (removed in 0.1.6): artillery shells, radar, railgun turret, explosive rockets, atomic bomb, nuclear reactor, vehicles, robots used Pyroclast materials
    - Custom Pyroclast rocket silo for launching from the planet
    - Works standalone with base + Space Age, or integrates with LavaBlock for extended tech tree
